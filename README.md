# Sunridge County

An original low-poly open-world action adventure that runs from **one HTML file**.

```
open index.html
```

That's it. No npm, no build step, no dev server, no asset folder. Three.js is pulled
from a CDN (with three fallbacks) the first time you open the page; everything else —
every building, vehicle, character, texture, sound effect and note of radio music — is
generated by code at load time.

## What's in it

| | |
|---|---|
| Story missions | 15, across four acts, with an ending |
| Side jobs, races and trials | 11 |
| Arcade minigames | 3 (plus the gym rig) |
| Driveable vehicle classes | 10 |
| Districts | 10, unlocked as the story moves |
| Hidden county relics | 20 |

Dez Arroyo comes home to Sunridge after six years away to find the family garage two
payments from the wrecking ball and a coastal developer quietly buying the county out
from under it.

## Controls

**On foot** — `WASD` move, `SHIFT` sprint, `SPACE` jump, `C` crouch, `F` fists,
`E` interact / enter a vehicle, mouse to look, wheel for camera distance.

**Driving** — `W`/`S` throttle and brake, `A`/`D` steer, `SPACE` handbrake,
`SHIFT` boost, `F` horn, `R` flip upright, `E` get out.

**General** — `M` county map, `TAB` stats, `V` radio, `H` help, `ESC` pause, `F3` debug.

## Look

Deliberately early-2000s: flat-shaded polygons, 64-pixel procedural textures, hard
distance fog, blob shadows, banded skies and a chunky bevelled HUD. The world is merged
into a few dozen chunk meshes and streamed by distance, so it draws in well under 200
calls.

## Testing

Press `F3` in game for the debug readout, then `P` to run the built-in self test — it
checks the road graph, terrain, every mission step, every marker and every location for
reachability. `window.SUNRIDGE` in the console exposes the game state and helpers
(`teleport`, `give`, `unlockAll`, `skipTo`, `spawn`, `test`).

All characters, places, brands, groups, vehicles and events are invented for this game.
